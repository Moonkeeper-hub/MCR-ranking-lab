## Возможности

- расчёт Legacy MCR по реконструированной формуле;
- изменение параметров расчёта в интерактивном режиме;
- исторический срез рейтинга на выбранную дату;
- последовательная симуляция турниров;
- сравнение экспериментальной конфигурации с Legacy default;
- поиск и сортировка рейтинговой таблицы;
- детализация истории отдельного игрока;
- экспорт рассчитанного рейтинга в CSV;
- поддержка экспериментальных справочников KT и VT;
- архитектура для подключения дополнительных рейтинговых методов.

## Локальный запуск

Требуется современная версия Node.js.

```bash
npm ci
npm run dev
```

`Production-сборка:`
```bash
npm run build
```
Готовые статические файлы создаются в каталоге dist/

## Формат данных
`players.csv`
player_id,player_name,initial_eu,initial_marks,initial_dan_date

Основные поля:
- player_id — уникальный идентификатор игрока;
- player_name — отображаемое имя;
- initial_eu — начальное значение EU;
- initial_marks — начальные успехи/неуспехи;
- initial_dan_date — дата последнего подтверждения дана.
Дополнительные колонки допустимы.

`results.csv`
tournament_id,tournament_name,tournament_date,tournament_order,player_id,place,participants,sessions,is_world_europe

Основные поля:
- tournament_id — идентификатор турнира;
- tournament_name — название турнира;
- tournament_date — дата турнира;
- tournament_order — порядок турниров при совпадении даты;
- player_id — идентификатор игрока;
- place — занятое место;
- participants — число участников;
- sessions — число игровых сессий;
- is_world_europe — признак турнира ЧЕ/ЧМ.
Дополнительные колонки допустимы и игнорируются движком.

## Исторический расчёт
`Дата рейтинга является жёсткой границей истории.`
При расчёте рейтинга на дату D турниры после D полностью исключаются из симуляции и не могут влиять на:
- EU;
- marks;
- подтверждение данов;
- KT;
- VT;
- T5;
- итоговый рейтинг.
Турниры обрабатываются последовательно в хронологическом порядке.

## Архитектура
`Расчётный слой отделён от интерфейса и источника данных.`
Data source
    ↓
normalized players / results
    ↓
rating engine
    ↓
simulation
    ↓
UI / comparison / export

`Текущая реализация Legacy находится в:`
src/engine/legacy.ts

`Последовательная симуляция:`
src/engine/simulation.ts

`Интерактивное представление формулы:`
src/ui/formulas.ts

Это позволяет добавлять новые рейтинговые методы отдельными модулями.

## Legacy reference data
Нормативные таблицы Legacy вынесены отдельно и используются как неизменяемые справочники:
- уровни кю/дан ↔ EU;
- KT по числу участников;
- VT / устаревание;
- константы формулы.
Экспериментальные изменения справочников выполняются только над копиями.
Проверка переноса
Legacy default был сопоставлен с предыдущей Python-реализацией на тестовом fixture.
Для проверяемых полей:
- current_eu;
- t5;
- rating;
- rank
получено полное совпадение.

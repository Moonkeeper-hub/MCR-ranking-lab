# Mahjong Rating Lab

**Mahjong Rating Lab** — клиентский исследовательский стенд для воспроизводимого расчёта, настройки, сравнения и симуляции рейтинговых систем маджонга.

Все расчёты выполняются непосредственно в браузере. Загружаемые CSV-файлы и синтетические datasets не отправляются на сервер.

## Методики

Сейчас в проекте доступны пять рейтинговых методик:

- **[Проектный MCR (Приложение 3)](docs/PROJECT_MCR.md)** — формализованная реализация проектной российской рейтинговой системы MCR по Приложению 3 v0.5.
- **[Legacy MCR (Новиков observed)](docs/LEGACY_MCR_OBSERVED.md)** — реконструкция фактически применявшейся логики legacy-рейтинга по наблюдаемому поведению опубликованных рейтингов.
- **[RR](docs/RR.md)** — внутренний российский рейтинг игроков в риичи.
- **[TrueSkill Tournament](docs/TRUESKILL_TOURNAMENT.md)** — турнирная multiplayer-модель TrueSkill по полному порядку итоговых мест.
- **[Elo-PL](docs/ELO_PL.md)** — Elo-like рейтинг на основе модели Plackett–Luce.

Подробные формулы, параметры и правила каждой методики вынесены в отдельные документы.

## Возможности

- независимый расчёт нескольких рейтинговых методик на одном dataset;
- отдельная валидация входных данных для каждого движка;
- интерактивное изменение параметров формул;
- пользовательские presets;
- исторические snapshots после каждого турнира;
- сравнение мест и рейтинговых значений;
- траектория отдельного игрока;
- метрика дистанции и сравнительные гистограммы;
- CSV- и SVG-экспорт;
- client-side cache и Web Workers для тяжёлых расчётов;
- встроенный Mock generator для воспроизводимых синтетических историй.

## Локальный запуск

Требуется современная версия Node.js.

```bash
npm ci
npm run dev
```

Production-сборка:

```bash
npm run build
```

Готовые статические файлы создаются в каталоге `dist/`.

## Интерфейс

Приложение разделено на три основные вкладки:

```text
Сравнение методик + история
Лаборатория
Mock generator
```

### Сравнение методик + история

Один и тот же набор `players.csv + results.csv` передаётся каждому рейтинговому движку независимо. Каждая методика сама определяет, какие турниры из набора допустимы для её расчёта.

Можно выбирать рейтинговые методы и presets, сравнивать итоговые позиции, просматривать исторические snapshots и траекторию отдельного игрока.

Абсолютные числовые шкалы разных рейтингов не предполагаются напрямую сопоставимыми. Универсальный объект сравнения — порядок игроков и изменение позиции.

### Лаборатория

В лаборатории выбирается конкретная методика. После этого доступны:

- интерактивная формула;
- описание параметров;
- коэффициенты и таблицы;
- экспериментальные controls;
- сохранение пользовательских presets.

Presets хранятся локально в браузере и не изменяют default-конфигурации.

### Mock generator

Mock generator создаёт воспроизводимые synthetic datasets с управляемой скрытой силой игроков, активностью, стабильностью, временным drift и различными шаблонами турниров.

Подробное описание: **[docs/MOCK_GENERATOR.md](docs/MOCK_GENERATOR.md)**.

## Формат данных

Основные входные файлы:

```text
players.csv
results.csv
```

Кратко:

```text
players.csv:
player_id,
player_name,
initial_eu,
initial_marks,
initial_dan_date,
include_in_rating
```

```text
results.csv:
tournament_id,
tournament_name,
tournament_date,
tournament_order,
player_id,
place,
participants,
sessions,
is_status_tournament,
is_substitute
```

Дополнительные колонки допустимы и могут использоваться отдельными движками или генератором.

Полное описание: **[docs/DATA_FORMAT.md](docs/DATA_FORMAT.md)**.

## Архитектура

```text
                     Data source
                         │
             ┌───────────┴───────────┐
             │                       │
          CSV import             Mock generator
             │                       │
             └───────────┬───────────┘
                         ↓
              normalized players/results
                         ↓
             method-specific validation
                         ↓
 ┌────────────────┬────────────────┬──────┬──────────────┬────────┐
 │ Project MCR    │ Legacy MCR     │  RR  │ TrueSkill    │ Elo-PL │
 └────────────────┴────────────────┴──────┴──────────────┴────────┘
                         ↓
              cached worker calculation
                         ↓
             ranking snapshots / history
                         ↓
       comparison / distance / timeline / export
```

Основные модули рейтинговых движков находятся в `src/engine/`.

## Статус проекта

Проект находится в стадии разработки и используется как вычислительный и исследовательский стенд.

Он предназначен для:

- воспроизведения рейтинговых систем;
- исследования чувствительности формул к параметрам;
- сравнения методов на одинаковой истории;
- генерации контролируемых synthetic datasets;
- проверки поведения рейтинговых алгоритмов на реальных и синтетических данных.

Некоторые параметры и трактовки доступны в лаборатории как экспериментальные и не являются частью default-конфигурации соответствующей методики.

# v0.28.2 — laboratory/comparison split

- RR editing moved out of Comparison and into Laboratory.
- Laboratory can switch between MCR-2026 and RR.
- Both methods expose interactive KaTeX formula tokens; clicking a token opens its explanation and linked controls/tables.
- Local user presets can be saved for either method. Presets are stored in browser localStorage only.
- Comparison uses canonical MCR-2026 default and RR default, with an optional saved user preset as a third method.
- Existing history/simulation UI is embedded below Comparison so comparison and temporal inspection live on the same page.
- RR explanations follow the supplied RR description: two-year window, A/B decomposition, R, W=K_N+K_H, decay, selection of tournaments, and staged-tournament coefficients.
- Current CSV schema does not encode accreditation/open-registration/stage structures, so eligibility is assumed to have been pre-filtered; staged historical weights use the supplied hardcoded player+tournament coefficients.

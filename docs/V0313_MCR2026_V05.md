# v0.31.3 — MCR-2026 aligned with Appendix 3 v0.5

Default MCR-2026 parameters are aligned with the supplied Appendix 3 v0.5.

## Normative defaults

- `KT_EU` includes substitutes.
- `KT_EU = floor_to_0.05(mean(EU) / 1000)`.
- Substitute EU policy: immutable `EU = 0`.
- `KT_ЧУТ`: `160 -> 1.50` added to the normative lookup table.
- Double Strike mode: `B` — the second iteration continues from the first and
  positive changes caused by the second iteration are applied again.
- Double Strike scope: every processed tournament.
- Inactivity: one minus after more than one year from the last confirming
  tournament and one additional minus for every following year.
- Two accumulated minuses demote one dan; the marks counter resets.
- 1 dan and below are protected from inactivity minuses.

## Laboratory alternatives retained

The following are intentionally retained as experimental options:

- Double Strike off;
- Double Strike A (provisional first pass / full recalculation);
- Double Strike only when newcomers appear;
- substitute EU = average of non-substitutes;
- substitute treated as newcomer;
- non-strict policies for participant counts missing from `KT_ЧУТ`;
- editable MCR coefficients and reference tables.

These alternatives are not the MCR-2026 default.

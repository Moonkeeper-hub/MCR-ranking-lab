# Elo-PL

Elo-PL — Elo-like рейтинговая модель на основе Plackett–Luce likelihood для полного порядка участников турнира.

Вместо сведения турнира к набору попарных матчей используется весь итоговый ranking одновременно.

## Начальное состояние

Default:

```text
rating0 = 1500
```

## Модель Plackett–Luce

Для полного порядка игроков вероятность результата задаётся как произведение условных вероятностей последовательного выбора:

```text
P(π) =
∏ exp(rπi / s)
  ─────────────
  Σ exp(rπj / s)
```

где:

- `r` — текущее рейтинговое состояние;
- `s` — scale / temperature;
- `π` — наблюдаемый порядок финиша.

## Обновление рейтинга

Изменение определяется градиентом log-likelihood:

```text
r' = r + Keff × ∂logP / ∂r
```

`Keff` формируется из базового K и дополнительных модификаторов.

## Размер турнира

В лаборатории можно настроить влияние числа участников на величину обновления.

Это позволяет менять чувствительность модели к результатам крупных и небольших турниров.

## Опыт игрока

Обновление может зависеть от числа уже сыгранных турниров.

Experience decay уменьшает чувствительность устойчивого игрока к отдельному новому результату.

## Число туров

Число ханчанов / туров может входить в эффективный коэффициент обновления как отдельный множитель.

## Minimum players

Турниры меньше заданного минимального размера могут исключаться из расчёта.

## Нормализация отображения

Доступны режимы:

```text
Off
0–1000
0–3000
```

Нормализация меняет только отображаемое значение.

Внутреннее состояние Elo-PL всегда остаётся на исходной рейтинговой шкале.

## Настраиваемые параметры

В лаборатории доступны:

- Base K;
- PL scale / temperature;
- влияние размера турнира;
- влияние опыта игрока;
- experience decay;
- влияние числа туров;
- minimum players;
- режим отображаемой нормализации.

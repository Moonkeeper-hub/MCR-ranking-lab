# RR — внутренний рейтинг по риичи

RR — внутренний российский рейтинг игроков в риичи.

Методика использует турнирные результаты за ограниченный рейтинговый период и объединяет две части рейтинга: устойчивую среднюю оценку результатов и показатель лучших выступлений.

## Итоговый рейтинг

```text
RR = A × 0.5 + B × 0.5
```

Оба веса доступны для настройки в лаборатории.

## Базовый ранг результата

```text
R = ((N - p) / (N - 1)) × 1000
```

где:

- `N` — число участников;
- `p` — итоговое место.

Первое место получает `1000`, последнее — `0`.

## Турнирный коэффициент

```text
W = K_players + K_hanchans
```

### Коэффициент числа ханчанов

| Ханчаны | Прибавка |
| --- | ---: |
| 1–8 | +0.20 за ханчан |
| 9–12 | +0.15 |
| 13–16 | +0.10 |
| 17–20 | +0.05 |
| 20+ | фиксированно 2.8 |

### Коэффициент числа игроков

| Игроки | Прибавка |
| --- | ---: |
| первые 60 | +0.10 за каждых 4 |
| 61–120 | +0.05 |
| 121–180 | +0.01 |
| 180+ | фиксированно 2.4 |

## Угасание результатов

Последние 12 месяцев учитываются полностью.

После этого вес уменьшается каждые два месяца на `1/7`.

После двух лет результат имеет нулевой вес.

## Первая часть рейтинга

```text
A = Σ(W × R × Age) / Σ(W × Age)
```

Если сыграно меньше пяти турниров, недостающие результаты добавляют `0` в числитель и `1` в знаменатель.

Если сыграно больше пяти турниров, в расчёт включается:

```text
5 + ceil(0.8 × (T - 5))
```

лучших результатов.

## Вторая часть рейтинга

```text
B = Σ top-4(W × R × Age) / Σ top-4(MAXK)
```

`MAXK` — четыре максимальных коэффициента турниров за рейтинговый период с учётом устаревания.

## Турниры со специальной отсечкой

Исторические специальные коэффициенты задаются для конкретной пары:

```text
tournament_id + player_id
```

Эти значения доступны для просмотра и изменения в лаборатории.

## Рейтинговый период

Default-модель использует двухлетний горизонт.

Данные старше рейтингового периода могут присутствовать в CSV, но не влияют на текущий RR после полного затухания веса.

## Настраиваемые параметры

В лаборатории можно изменять:

- веса `A` и `B`;
- количество базовых и дополнительных учитываемых турниров;
- число лучших результатов второй части;
- таблицы коэффициентов игроков и ханчанов;
- параметры устаревания;
- специальные коэффициенты отдельных турниров.

# Проектный MCR (Приложение 3)

Проектный MCR — формализованная реализация рейтинговой системы спортивного маджонга MCR по Приложению 3 v0.5.

Default-конфигурация предназначена для буквального воспроизведения проектного описания. Экспериментальные альтернативы доступны отдельно в лаборатории.

## Итоговый рейтинг

```text
Rating = 0.25 × EU + 0.75 × T5
```

где:

- `EU` — текущий эволюционный уровень игрока;
- `T5` — показатель пяти лучших турнирных результатов.

## Норморейтинг

```text
NR = 1000 × (ЧУТ - место) / (ЧУТ - 1)
```

Первое место получает `NR = 1000`, последнее — `0`.

## Коэффициент турнира

```text
KT = KT_ЧС + KT_ЧУТ + KT_EU + KT_W
```

### KT_ЧС

```text
KT_ЧС = sessions × 0.1
```

### KT_ЧУТ

`KT_ЧУТ` определяется по нормативной таблице.

Default использует строгий lookup. Если значение ЧУТ отсутствует в таблице, расчёт такого турнира не интерполируется автоматически.

В лаборатории доступны экспериментальные режимы обработки отсутствующего ЧУТ:

- strict;
- ближайшее нижнее значение;
- ближайшее значение;
- линейная интерполяция;
- исключение турнира.

### KT_EU

```text
KT_EU = mean(EU участников) / 1000
```

Результат округляется вниз с шагом `0.05`.

### KT_W

Для статусного турнира:

```text
KT_W = 1
```

Для обычного:

```text
KT_W = 0
```

## EU и ранги

Для игрока 1 кю и ниже условие

```text
EU_before <= NR × KT
```

позволяет присвоить уровень, соответствующий ближайшему снизу значению EU.

Для данового игрока превышение `NR × KT` над текущим EU преобразуется в плюсы.

Default-модель использует установленное в движке взаимное погашение плюсов и минусов. Два плюса переводят игрока на следующий дан.

В лаборатории можно отдельно включить ограничение продвижения из кю максимум первым даном за один турнир.

## Временное понижение

Проверка выполняется последовательно при обработке турниров для игроков, которые не участвуют в текущем событии.

`initial_dan_date` трактуется как дата последнего турнира до начала загруженной истории, на котором было выполнено условие подтверждения соответствующего данового EU.

## T5

```text
T5 = Σ top-5(NR × KT × VT) / 5
```

Даже если у игрока меньше пяти результатов, деление выполняется на 5.

## Double Strike

Default:

```text
Mode: B
Scope: every_tournament
```

Доступные режимы:

- `Нет`;
- `A — полный пересчёт`;
- `B — продолжение первой итерации`.

Режим B выполняет первую итерацию, пересчитывает KT по обновлённому состоянию и продолжает применение положительных изменений.

## Игроки замены

Default:

```text
substitute EU = 0
```

В лаборатории также доступны экспериментальные политики:

- среднее арифметическое;
- считать замену новичком.

## Внешние игроки

`include_in_rating=false` означает, что игрок:

- участвует в турнире;
- влияет на расчёт состава и результаты других игроков;
- не отображается во внутренней итоговой рейтинговой таблице.

## Default-конфигурация

Ключевые значения:

```text
rating = 0.25 × EU + 0.75 × T5
T5 = top 5
KT_EU rounding = floor to 0.05
Double Strike = B
Double Strike scope = every_tournament
substitute EU = 0
successes per dan step = 2
dan step = 500
```

Экспериментальные настройки в лаборатории не изменяют default-конфигурацию.

# TrueSkill Tournament

TrueSkill Tournament — турнирная multiplayer-модель, в которой весь турнир рассматривается как одно наблюдение по полному порядку итоговых мест.

Текущая реализация предполагает строгий порядок мест без ничьих.

## Состояние игрока

Каждый игрок описывается двумя параметрами:

```text
μ
σ
```

где:

- `μ` — текущая оценка силы;
- `σ` — неопределённость этой оценки.

Default-параметры:

```text
μ0 = 25
σ0 = 25 / 3
β = 25 / 6
```

## Рейтинговое значение

Для сортировки используется conservative score:

```text
score = μ - kσ
```

Default:

```text
k = 3
```

Чем выше неопределённость игрока, тем сильнее она уменьшает отображаемый conservative score.

## Турнир как multiplayer-наблюдение

Все места турнира обрабатываются одновременно.

Модель обновляет распределения игроков с учётом:

- текущих `μ` и `σ`;
- итогового порядка мест;
- параметра производительности `β`;
- неопределённости каждого участника.

## Календарный τ / decay

Между турнирами неопределённость игрока может увеличиваться:

```text
σprior = sqrt(σ² + τ² × Δt_years)
```

Множитель календарного decay задаётся отдельно.

Типовые значения:

```text
0 — календарное устаревание выключено
1 — default
3 — усиленное устаревание
```

## Турнирная поправка

После базового TrueSkill update может применяться дополнительный вес турнира:

```text
μ' = μ + wT(μTS - μ)
σ' = σ + wT(σTS - σ)
```

`wT` может учитывать:

- число участников;
- число туров / ханчанов.

Если общий коэффициент турнирной поправки равен `0`, дополнительное масштабирование выключено.

## Настраиваемые параметры

В лаборатории доступны:

- стартовое `μ`;
- стартовое `σ`;
- `β`;
- коэффициент conservative score `k`;
- календарный `τ`;
- сила calendar decay;
- влияние размера турнира;
- влияние числа туров;
- общий коэффициент турнирной поправки.

## Исторический расчёт

Турниры обрабатываются последовательно.

После каждого события создаётся новое состояние `μ/σ` и исторический snapshot отображаемого рейтинга.

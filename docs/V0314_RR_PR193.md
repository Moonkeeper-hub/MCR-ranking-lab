# v0.31.4 — RR PR #193

RR default now follows MahjongRepository/mahjong-portal PR #193 `Smooth tournament decay`.

Default P1 selection:
- first 5 tournaments: full weight;
- after that the effective credited tournament count is continuous:
  `q(T) = 5 + 0.8 * (T - 5)`;
- examples: 6 -> 5 full + 0.8 partial; 7 -> 6 + 0.6; 8 -> 7 + 0.4;
  9 -> 8 + 0.2; 10 -> 9 full; then cycle continues;
- the tournament receiving partial/zero weight is chosen so that P1 is maximized;
- the fractional factor multiplies both numerator and denominator contribution.

Laboratory option:
- `legacy_discrete`: old `5 + ceil(0.8 * (T - 5))` selection.

Sessions fallback:
- when `sessions == 0`, use portal fallback based on available tournament start/end dates:
  1 day -> 4 sessions, 2 days -> 8, 3+ days -> 12;
- if dates are missing, fallback remains 0 and ordinary RR eligibility diagnostics apply.

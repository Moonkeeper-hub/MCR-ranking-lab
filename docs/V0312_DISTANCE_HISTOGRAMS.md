# v0.31.2 — Patrick histogram normalization

Метрика пар остаётся ревизии 2:

- до первого #1 пара создаётся только при строгом улучшении личного лучшего места;
- после первого #1 считаются расстояния до повторного #1;
- после последнего #1 сохраняется остаток турнирной дистанции до конца истории;
- если #1 не достигнут, незавершённый отрезок после последнего личного рекорда не добавляется.

Изменена только агрегация гистограмм согласно уточнению Патрика.

## Гистограмма 1 — накопленная дистанция

Для каждого места рейтинга (или диапазона при шаге > 1):

`Y1 = Σ distance / T`

где:

- `distance` — численное значение первого элемента пары `(число турниров; достижение)`;
- `T` — число турниров, учтённых в рейтинге данной методикой.

То есть внутри колонки сначала накапливаются все дистанции, затем колонка нормируется на турнирный объём рейтинга.

## Гистограмма 2 — число пар

Для того же места/диапазона:

`Y2 = count(pairs) / P`

где `P` — число игроков, присутствующих в рейтинге данной методики.

Каждая пара добавляет в соответствующую колонку ровно единицу до нормировки.

## Важно

Предыдущая величина `meanTournaments = Σ distance / count(pairs)` больше не используется в визуализации.
Она оставлена только как внутреннее совместимое поле структуры данных.

Полиномиальная аппроксимация/МНК в этом патче отсутствует.

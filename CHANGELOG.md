## Changelog

## v0.26

- Legacy-модель приведена к формализованной версии **MCR-2026**.
- `Rating`, `NR`, `T5` и `VT` приведены в соответствие с текущим описанием расчёта.
- `KT_ЧУТ` переведён на строгий lookup по нормативной таблице без интерполяции.
- Сохранено округление `KT_EU` вниз с шагом `0.05`.
- `KT_W` переосмыслен как бонус статусного турнира.
- Исправлено взаимное погашение плюсов и минусов у дановых игроков.
- Изменён порядок временного понижения: проверка выполняется при обработке турнира только для игроков, не участвующих в нём.
- Убрано календарное изменение EU между турнирами без события расчёта.
- `initial_dan_date` теперь трактуется как дата последнего турнира, на котором выполнено `EU_before <= NR × KT`.
- Добавлены три режима Double Strike:
  - `Нет`;
  - `A — полный пересчёт`;
  - `B — продолжение первой итерации`.
- Double Strike применяется при появлении нового игрока.
- Добавлены три политики EU игроков замены:
  - `EU = 0`;
  - `среднее арифметическое`;
  - `считать новичком`.
- Добавлено поле `is_substitute`.
- `is_status_tournament` заменяет прежнюю семантику `is_world_europe`; старое поле временно поддерживается как alias.
- Demo dataset перестроен под MCR-2026:
  - 120 синтетических игроков;
  - 83 турнира;
  - только допустимые значения ЧУТ;
  - количество результатов каждого турнира соответствует ЧУТ;
  - добавлены игроки замены;
  - добавлены статусные турниры;
  - для импортированных дановых игроков задана предыстория через `initial_dan_date`.

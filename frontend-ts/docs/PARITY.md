# Python ↔ TypeScript parity

Перед упаковкой v0.20 Legacy engine был проверен на встроенном 12-player fixture из Python v0.10.

Проверялись для каждого игрока:

- `current_eu`;
- `t5`;
- `rating`;
- итоговый `rank`.

Результат: 12/12 строк совпали, максимальная абсолютная ошибка = 0.

Также расчёт RR/offline набора из 776 игроков и 3611 результатов был прогнан локально в Node.js: около 86 ms в тестовом окружении. Это подтверждает, что данный объём нет необходимости считать на VPS.

Проверка относится к Legacy default на дате выпуска 2026-10-02. После изменения алгоритма parity test следует повторять.
